# ProGo 0.2.2

Лёгкое приложение для Windows: подключение к своему серверу, прокси для приложений,
домашний VPN для iPhone и Android и локальное хранилище паролей. Без телеметрии и серверов
разработчика. Русский интерфейс; .NET Framework 4.8, Windows 10/11, OpenSSH.

## Начало работы

1. Откройте ProGo двойным щелчком по значку рядом с часами.
2. В **Настройки → Подключение → Добавить → По адресу сервера** укажите адрес
   VPS, пользователя, SSH-порт и путь к ключу. Если используете готовую запись
   OpenSSH, выберите **Из SSH config (для опытных)**.
3. **Первый вход** открывает обычное окно SSH для проверки ключа сервера.
   Для фонового подключения нужен разрешённый SSH-ключ или агент; вход по паролю
   сам по себе его не настраивает.
4. Нажмите **Запустить CLI** для Codex и терминалов либо включите Windows.
   После «Запустить CLI» можно запускать `codex` обычным способом без специального
   ярлыка. Сам Codex CLI установите отдельно. Полностью перезапустите старые
   терминалы, IDE и Codex, чтобы они получили новые переменные прокси.
5. Готовность SOCKS и проверенный интернет — разные состояния. Используйте
   **Проверить маршрут**. Подключение не перенаправляет весь трафик компьютера.

Пример записи в `%USERPROFILE%\.ssh\config`:

```sshconfig
Host my-vps
  HostName vpn.example.org
  User deploy
  IdentityFile ~/.ssh/id_ed25519
```

## Автоматика и ручное управление

В **Настройки → Автоматика** есть три настройки:

| Настройка | Что делает |
| --- | --- |
| Восстанавливать подключение при обрыве | Восстанавливает свой SSH/SOCKS после сбоя; ручная остановка отменяет повторы. Работает и для отдельного канала телефона. |
| Включать прокси для терминалов и Codex | Применяет одно общее окружение прокси текущего пользователя для новых терминалов и обычного запуска Codex. Специальный ярлык не требуется. |
| Включать прокси для приложений Windows | Включает HTTP/HTTPS-прокси текущего пользователя для приложений, учитывающих настройки Windows. |

Старые галочки терминалов и Codex объединяются: включение любой из них сохраняет
общую автоматику. Явно сохранённое выключение общей настройки не отменяется
миграцией. На новой установке режимы включаются вручную. Необязательный отдельный
ярлык доступен в **Прокси для приложений → Дополнительно: ярлык Codex**.

Снятая галочка означает ручное управление: она не отключает уже включённую функцию.
Для этого есть кнопка рядом. Ручное выключение не отменяется фоновым таймером;
автоматическое действие повторится при следующем запуске ProGo или явном снятии
и повторном включении галочки с сохранением. Галочка **Подключаться к серверу при
запуске ProGo** находится во вкладке «Подключение».

Закрытие главного окна оставляет приложение в трее. **Отключить прокси на ПК** останавливает
настольный режим и отменяет ожидающие автоматические действия; телефон управляется отдельно; **Завершить работу ProGo**
закрывает приложение. При остановке восстанавливаются предыдущие значения прокси,
если ими всё ещё управляет ProGo. Уже запущенные терминалы нужно перезапустить.

## Если порт занят

Откройте **Настройки → Порт приложений**.

- **Выбирать свободный порт автоматически** — включено по умолчанию. ProGo пробует
  последний сохранённый порт; если он занят, сам выбирает свободный и сохраняет его.
- Снимите галочку, чтобы указать постоянный порт вручную. Если он занят, приложение
  покажет объяснение и сохранит прежнее работающее подключение.
- **Подобрать свободный** выбирает новый порт после нажатия **Сохранить**. Текущий
  режим (автоматический или ручной) при этом сохраняется.
- Текущий адрес показан на главной и в настройках; рядом есть **Скопировать адрес**.

Порт меняется при запуске прокси или сохранении ваших настроек. Во время нормальной
работы он остаётся прежним. Прикладные настройки Windows, общего окружения и дополнительного ярлыка Codex,
которыми управляет ProGo, обновляются вместе. Чужие настройки не перезаписываются.
**После смены порта перезапустите уже открытые терминалы и Codex.**

Это порт HTTP-прокси на вашем компьютере. Порты SSH, SOCKS и VPN для телефона
настраиваются отдельно. Первоначальный порт — 1881; точный адрес берите из приложения.

## VPN для телефона

Откройте **VPN для телефона** на главной или **VPN для телефона…** в трее.
Мастер предлагает **Подключиться к готовому VPS** по токену либо **Добавить свой VPS**
по SSH. Он показывает правила роутера, выдаёт профиль и помогает проверить канал.
Роутер настраивается вручную; галочка пользователя не доказывает доступность портов.

**Установить на телефон по QR** создаёт временную ссылку на HTTPS-страницу VPS.
На ней выбирается iPhone или Android. iPhone устанавливает профиль через Safari
и настройки iOS; Android использует strongSwan VPN Client. Для QR нужен отдельный
HTTPS-домен VPS. **Сохранить профиль iPhone файлом…** выдаёт только .mobileconfig
для iPhone. Сам профиль не помещается внутрь QR.

QR или сохранение файла не подтверждают установку. Подтвердите её отдельно в мастере,
а затем на мобильной сети проверьте статус VPN, открытие сайта и IPv4 выхода VPS.
Пакеты канала не доказывают наличие интернета. Владелец выдаёт отдельные токены
через **Доступ друзей…** и может отозвать конкретного пользователя. Срок ссылки QR
и срок очистки скопированного содержимого буфера — разные настройки.

В 0.2.0 исправлена ошибка установки `Invalid DH group (0)`. Если профиль создан
старой версией, откройте мастер → **Настроить роутер / создать профиль снова**,
сохраните новый файл и установите его на iPhone. Перенастройка VPS не требуется.

Режим экспериментальный: нужны доступный извне домашний IPv4, два UDP-порта на
роутере и работающий ПК. Реальный маршрут проверяется на телефоне.
[Подробная инструкция](docs/HOME_IKEV2.md).

## Обновление и антивирус

Нажмите **Обновить ProGo** на главной или **Проверить обновления…** в трее.
Версия 0.2 использует установленный файл обновления, скачивает пакет опубликованного
релиза и сверяет SHA-256 по данным GitHub до распаковки. Затем создаёт резервную
копию, проверяет промежуточную установку и заменяет приложение. При ошибке
замены выполняется восстановление. Настройки и хранилище сохраняются.

Удалённые PowerShell-скрипты больше не исполняются в памяти, исходники при обновлении
не собираются. При невозможности проверить пакет обновление останавливается.
Старые версии при первом переходе используют свой прежний механизм проверки пакета.

**Помощь** на главной или **Помощь и журналы → Открыть помощь…** в трее
открывает темы подключения, Codex и терминалов, портов, телефона, восстановления
и антивируса. Тема **Антивирус** содержит ссылки на выпуск и
Kaspersky OpenTIP. ProGo не отключает антивирус и не добавляет исключения.
Исполняемый файл пока без подписи Authenticode. Проверка SHA-256 не заменяет подпись
издателя и не гарантирует отсутствие срабатываний.

Если старый апдейтер заблокирован, получите [официальный архив](https://github.com/rkhnorkhan-bit/ProGo/releases/latest)
через браузер. Сначала разберите обнаружение с антивирусом; не отключайте защиту
ради установки. После разрешения проблемы закройте ProGo, сохраните копию его
папки и распакуйте содержимое архива в `%LOCALAPPDATA%\ProGo` с заменой файлов
программы. Не удаляйте `settings.json`, хранилище, резервные копии и личные данные VPN.

## Ограничения

- Системный прокси действует только для приложений, учитывающих настройки Windows.
- Командная строка использует локальный HTTP-прокси с выбранным портом; SSH/SOCKS остаётся его транспортом.
- Уже открытые окна не получают новые переменные окружения автоматически.
- Хранилище использует AES-256-CBC, HMAC-SHA256 и PBKDF2-HMAC-SHA256. Четырёхзначный
  PIN имеет лишь 10 000 комбинаций и не является сильным мастер-паролем.
- Пароли, ключи, токены, профили телефона и содержимое хранилища не публикуйте.
