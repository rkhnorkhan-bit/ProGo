## Блокер публикации и нового Windows CI

GitHub get_repo по имени и URL независимо возвращает `visibility=public`.
Поручение определяет приватный репозиторий и приватный проверочный пакет.
Новые коммиты пока только локальные; push, обновление PR и новый CI не выполнены.
Для продолжения требуется уточнение владельца о публичном push либо перевод
репозитория в Private. Видимость и права репозитория автоматически не менялись.
